# VOIDSTORM 4

Аркадный космический шутер: **250 секторов / 25 регионов**, 50 боёв с боссами, 10 классов боссов, 23 обычных противника, 10 корпусов и 20 рангов трёх общих систем флота.

## Запуск

Откройте index.html или выполните npm start и перейдите на http://127.0.0.1:4173. Устанавливать зависимости для игры не нужно. Для публикации нужны index.html, style.css, ui-theme.css, js/, assets/ и music.mp3.

Мышь, палец, WASD/стрелки — движение; огонь автоматический; Esc/P — пауза. На телефоне корабль следует над пальцем с коротким сглаживанием без инерции. Во время рекламы новый полёт не запускается.

## Версия 4

- Снабжение прибывает сверху с началом следующей волны. На передышке модули не тратят время и оружие не стреляет.
- Старый ранг двигателя перенесён в скорострельность. Урон +7%, броня +9%, частота залпов +2,5% от базовых значений за ранг. Все системы действуют на весь флот.
- Наведение даёт 25% мощности поддерживающих ракет, ограничено передним конусом ±17°, дальностью захвата 520 и скоростью поворота 0,85 рад/с. Основное оружие стреляет прямо. Это не ракеты, преследующие цели по всему экрану.
- Центральная зона повреждения — эллипс 34 × 52 игровых единицы. Кончики крыльев и свечение снарядов не учитываются; для быстрых пуль проверяется весь пройденный отрезок.
- 14 новых противников, 10 отдельных ассетов боссов, 16 растровых эффектов снарядов. Боссы имеют собственные батареи, движение, паузы, броню, мины и эскорт.
- Кредиты за первые прохождения поддерживают покупку всех корпусов и прокачку на протяжении кампании. Чертежи открываются в секторах 10, 28, 50, 78, 110, 145, 180, 215, 240. Эскорт босса не приносит кредитов.
- VK: постоянный нижний баннер, повторная попытка при отсутствии рекламы, межэкранная реклама после каждого третьего полёта длительностью от 15 секунд с интервалом не менее 3 минут. Реклама запускается после сохранения результата, независимо от загрузки облачного профиля.

## Сохранения

Прежние ключи voidstorm_save и voidstorm_data_<VK id> сохранены. Купленные корпуса не отбираются даже при новых требованиях чертежей. Прогресс, кредиты и ранги мигрируют в version 4. Пройденная старая кампания на 120 секторов открывает сектор 121; версия на 40 секторов — сектор 41. Перед миграцией создаётся резервная копия профиля.

## Проверки

- npm test — логика, миграция, механики, экономика и VK с имитацией Bridge.
- npm run check — синтаксис.
- npm run test:economy — экономика при 60%, 75% и 90% уничтоженных врагов, без бонусов или повторных прохождений.
- node tests/simulate-balance.cjs — детерминированные боевые прогоны. PROBE_LEVELS и PROBE_SEEDS задают список через запятую; PROBE_ALL=1 проверяет все 250 секторов активным пилотом.
- npm run test:browser — Edge/Playwright: реальные клики и touch, покупки, перезагрузка, размеры экрана, кадры и снимки. Нужен Playwright; путь можно задать PLAYWRIGHT_MODULE.

Боты проверяют проходимость и резкие скачки, а не заменяют тестирование людьми на телефоне. Сетевые проверки рекламы выполняются на живом приложении VK с включённой монетизацией: локальный тест подтверждает вызовы и сценарии ошибок, но не наличие рекламного инвентаря.

Подробности: docs/balance-v4.md, docs/vk-integration.md. Отчёты — docs/qa. PNG — исходники графики, WebP — оптимизированные игровые файлы.
