# VOIDSTORM 5.1

Космический аркадный шутер: **300 секторов, 12 кораблей, 27 противников, 13 боссов**. Три системы каждого корабля улучшаются отдельно по 5 рангов. 12 глав по 25 секторов, выживание со сложности текущей кампании.

## Запуск

Откройте index.html или выполните npm start и перейдите на http://127.0.0.1:4173. Игре не нужны устанавливаемые зависимости. Публикуются index.html, style.css, ui-theme.css, js/, assets/ и music.mp3.

## Версия 5.1

- Свободная покупка любых корпусов и всех рангов за кредиты, без условий по секторам и предыдущим кораблям. Прогрессивные цены до 301 400 CR; подробный расчёт: [docs/balance-v5.1.md](docs/balance-v5.1.md).
- Шкалы показывают класс корпуса и прокачку по единой шкале флота; следующий корпус визуально сильнее предыдущего.
- В каждой волне 12–21 враг; следующий базовый корабль сильнее предыдущего полностью улучшенного. Победа требует 75% уничтоженных противников.
- Гелиос и Левиафан; четыре новых противника; Хронос, Кракен и Обелиск с лучами, астероидами и пилонами.
- Бесконечное выживание начинается с текущего сектора, постоянно наращивает сложность и ограничивает количество объектов.
- Короткие правила, переключаемая вибрация при уроне, исправлено мигание выбора систем.
- Старые покупки и прогресс сохраняются, общие улучшения возвращаются кредитами; резервная копия перед миграцией. Все купленные корпуса доступны сразу. Уведомление о переносе улучшений убрано.
- Сохраняются быстрое следование пальцу, таймеры модулей без расхода на передышке, снабжение сверху, растровые снаряды и центральная зона попадания.

VK: постоянный нижний баннер и межэкранная реклама после каждого третьего полёта от 15 секунд, с интервалом не менее 3 минут. Запрос рекламы не зависит от успешности загрузки профиля; доход сохраняется до запроса. См. [docs/vk-integration.md](docs/vk-integration.md). Вибрация использует браузерный API или поддерживаемый [VK Taptic API](https://github.com/VKCOM/vk-mini-apps-api/blob/master/src/index.ts).

## Проверки

- npm test — баланс, экономика, миграция, механики, сохранения, вибрация и VK с имитацией Bridge.
- npm run check — синтаксис.
- npm run test:economy — все 300 первых прохождений при 75%, 90% и 100% уничтожений.
- node tests/simulate-balance.cjs — реальные боевые симуляции; PROBE_ALL=1 запускает все 300 секторов. PROBE_LEVELS, PROBE_SEEDS, PROBE_SHIP, PROBE_RANK задают контрольные условия.
- npm run test:browser — Edge/Playwright, нужен запущенный локальный сервер. PLAYWRIGHT_MODULE задаёт путь к Playwright.

PNG — исходные атласы, WebP — игровые файлы. UV-границы пересчитываются tools/build-atlas-manifest.cjs. Промоматериалы в promo-local/ остаются локально и исключены из публикации. Автопилот и настольный браузер не заменяют проверку на телефоне; реальные показы рекламы зависят от среды VK и наличия инвентаря.
