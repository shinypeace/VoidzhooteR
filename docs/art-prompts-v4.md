# VOIDSTORM 4 — production assets

Generated with the imagegen skill / built-in image generator. PNG masters retain alpha; production WebP uses quality 92 and alphaQuality 100. No external game assets used.

Expansion atlas: 4 × 4, first six cells are enemies, remaining ten are bosses. Projectile atlas: 4 × 4. Reinforcements atlas: 2 × 4, eight enemies. UV bounds in js/atlas-frames.js are derived from each PNG alpha island by tools/build-atlas-manifest.cjs. This avoids neighbouring sprite tips leaking between imperfect atlas cells. Aspect ratios are preserved. Projectile cells use a small inset. Cell 2 of reinforcements has a native downward nose and receives a 180° correction.
